# 双卡智算液冷一体机（海光5380）工作站搭建 — 设计文档

日期：2026-11-03

## 背景与目标

用户手头只有一块海光5380适配的 ATX 主板，目标是搭建一台**双智算卡液冷一体机工作站**。素材存放在 `tmpworkstation/双卡智算液冷一体机（海光5380）/`（图片 2 张、GPU 规格书 PDF 2 份、项目管理 xlsx 1 份），需要：

1. 提取并整理素材（图片 OCR / PDF 文本提取 / xlsx 表格）
2. 基于整理结果 + 网络资料，产出**完整采购清单**（预算未定，先出完整方案）
3. 产出**搭建指南**（液冷要点、走线、适配）
4. 整理**参考资料**：常规网站 + B站装机教程（链接清单 + 要点点评，若用户提供视频则转录提炼）

## 已确认需求（来自项目管理表）

- CPU：海光 5380（7380 / 7420D 备选；飞腾 S5000C 32核备选）→ 已定 5380
- 内存/硬盘：需 2.5 寸 SATA（主板无 M.2 接口）；硬盘参考致钛 Ti600 4TB
- 电源：ATX 1600W（素材图为 1650W ATX 电源）
- 散热：CPU + GPU 全液冷；GPU 改液冷后为单宽
- 智算卡（二选一）：
  1. 沐曦 X201（规格书参考：京宏 JH501）——双卡需隔一个 PCIe 槽配硬桥接片
  2. 奕行智能 E100（规格书参考：银河 YH-S100E）——双卡软排线互联，不需隔槽
- 机箱候选：华硕 WS702（70L，GPU 最长 400mm）；华硕 PRIME AP303（30L）
- 时间预期：1-2 周出样机，2-4 周做适配
- 用途：会加 GPU，具体负载未定 → 采购/搭建指南需覆盖三种参考案例（AI 算力主力机 / 样机验证 / 通用工作站）

## 实现方案（已批准：方案 A）

**复用并参数化 tmpmission 的 `convert_haiguang_docs.py`，不新写脚本。**

### 脚本改造（最小改动）
- 增加 `--src` / `--out` 命令行参数，默认值保持原 tmpmission 路径（向后兼容）
- 增加 jpg/jpeg/png 图片处理分支：Tesseract OCR（autocontrast + 二值化增强，chi_sim+eng），复用脚本内 pptx 图片 OCR 的增强逻辑
- 其余逻辑（docx/xlsx/pptx/pdf 提取、OCR 兜底）不变

### 素材提取
- GPU PDF ×2 → 文本提取（有可选文本走 PyPDF2；JH501 可能乱码需 OCR 兜底）
- xlsx → markitdown 表格提取
- 图片 ×2（CPU 参数、电源）→ Tesseract OCR

### 交付物（Markdown 手册，存放到 tmpworkstation 工作区）
1. `素材整理/`：各素材提取的结构化 Markdown（含来源标注）
2. `采购清单.md`：完整清单（含三类用途参考案例）
3. `搭建指南.md`：搭建步骤 + 液冷要点 + 适配注意事项
4. `参考资料.md`：常规网站 + B站教程链接清单与点评；用户提供视频时转录提炼要点

## 成功标准
- 素材全部提取成功（图片 OCR 可读、PDF 正文可用、xlsx 关键信息完整）
- 采购清单覆盖：CPU/内存/硬盘/电源/机箱/智算卡/液冷套件/线材/工具，每项含型号、要点、参考价
- 搭建指南可指导完成实际组装
- 参考资料含 B站链接与点评
